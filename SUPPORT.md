# Support

## Getting help

For reproducible bugs and concrete improvement proposals, open an issue using the appropriate template.

Before opening an issue:

1. Read the README setup instructions.
2. Confirm the issue occurs on the current default branch.
3. Search existing issues for the same problem.
4. Include your operating system, browser, Node.js version, steps to reproduce, and relevant non-sensitive logs.

## What to include

For display or interaction issues, include the affected page, viewport size, browser, expected behaviour, actual behaviour, and screenshots where useful. For 3D rendering problems, mention browser WebGL support and graphics environment if known.

## Security and private matters

Do not post credentials, personal information, or vulnerability details publicly. Follow [SECURITY.md](SECURITY.md) for security reports.

Support is provided on a best-effort basis. No response time is guaranteed.
