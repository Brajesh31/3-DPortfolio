# Roadmap

This is a discussion-oriented list of possible maintenance areas, not a promise or release commitment.

## Maintenance priorities

- Keep setup and deployment instructions aligned with the repository.
- Review dependency security advisories and update dependencies deliberately.
- Improve keyboard and screen-reader usability across all portfolio views.
- Validate reduced-motion behaviour for animation-heavy sections.
- Improve resilience when WebGL is unavailable or device resources are limited.
- Add an automated test strategy if the project adopts a test framework.
- Review contact-form spam prevention and privacy disclosures.
- Document browser support and deployment routing requirements.

Prioritize work through GitHub issues and maintainer review.
