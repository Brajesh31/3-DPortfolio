## 🧭 About This Changelog

The repository has not yet adopted a formal release cadence or a release automation policy. Entries should be added when changes are meaningful, grouped by release or development period when practical.

This file should not be used to claim that a feature is shipped when it exists only as an idea or an open pull request.

## 🔖 Change Categories

- **Added:** new user-visible functionality or documentation.
- **Changed:** modifications to existing behaviour or workflow.
- **Fixed:** corrections to defects.
- **Security:** security improvements or dependency fixes.
- **Deprecated:** functionality that is planned for removal.
- **Removed:** features or files removed from the project.
- **Maintenance:** internal changes that materially affect development or operations.

## 📝 How to Maintain This File

When a meaningful change is merged:

1. Add an entry under the correct category.
2. Describe the user or maintainer impact, not just the file name.
3. Reference an issue or pull request when one exists.
4. Keep unreleased changes under `Unreleased`.
5. Move completed entries into a dated release section when a release is prepared.
6. Do not invent version numbers or release dates.

A changelog entry is a summary, not a substitute for detailed migration or deployment instructions.
